# BelGrano Café - Sitio web para mostrar el output de los tests

Sitio web y aplicación interactiva diseñada para demostrar y evidenciar la ejecución y el output de los tres niveles de pruebas de software (Unitarias, Integración y End-to-End), tanto en entorno local como en los flujos continuos de GitHub Actions CI. Proyecto desarrollado para la cátedra **Ingeniería y Calidad de Software (UTN FRRO)**.
